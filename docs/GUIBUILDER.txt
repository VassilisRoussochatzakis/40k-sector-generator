# SPECIFICATION: INTERACTIVE SECTOR BUILDER GUI (GUIBUILDER.txt)

> Target crate moved 2026-05-24 from `sectorforge-viewer` to
> `sectorforge-builder`. References to `viewer/src/builder/` in older revisions
> now point to `builder/src/builder/`.

## GOAL
Transition from a "scaffold-then-cli-generate" workflow to a fully interactive, real-time sector design environment within the dedicated Sectorforge builder GUI (`sectorforge-builder`).

## 1. REAL-TIME GENERATION & FEEDBACK
- [x] LIVE PREVIEW: Updating generation settings (density, cluster bias, world types) should re-render the hex map immediately (or via a "Re-roll" button with the same seed).
- [x] SEED LOCKING: Ability to lock the seed while changing dimensions or distribution parameters.
- [x] PARTIAL GENERATION: Generate specific subsectors or systems without wiping manual changes in others.

## 2. INTERACTIVE PLACEMENT & EDITING
- [x] DRAG-AND-DROP SYSTEMS: Move existing systems between hexes with automatic route recalculation.
- [x] TOOLBOX:
    - [x] "Add System" brush (click hex to place).
    - [x] "Delete" tool (remove systems/routes).
    - [x] "Route" tool (click-drag between systems to create manual warp lanes).
- [x] PROPERTY INSPECTOR: Side panel to edit system names, world counts, and faction presence on the fly.

## 3. CONSTRAINT-BASED DESIGN
- [x] GUI FOR WISHES: Visual editor for `wishes.toml` (e.g., "I want at least 3 Forge Worlds", "Ensure Faction X has a base here").
- [x] SEARCH INTEGRATION: Run the "Search & Candidate" logic within the GUI, showing multiple candidate thumbnails to pick from.

## 4. DIMENSIONS & SCAFFOLDING (Refined)
- [x] DYNAMIC RESIZING: Expand or shrink sector dimensions in the editor.
- [x] AUTO-SQUARE: Default to square (H=W) as established.
- [x] IRREGULAR WARNINGS: Persistent UI warning when dimensions are non-standard (segmentum joining risks).

## 5. PROJECT INTEGRATION
- [x] AUTO-SAVE: Optional background saving to `sector.json` on every change.
- [x] VERSIONING: Integration with the `History` tab to "Snapshot" a state and revert if a re-roll goes poorly.
- [x] EXPORT SYNC: One-click refresh for PNG/HTML exports after manual edits.

## 6. SEGMENTUM JOINING (Phase E; not part of the SEPARATE split)
- [ ] STITCHING PREVIEW: Visual builder tool to align two sectors and see how routes/influence cross the boundary. CLI segmentum composition already exists in `sectorforge`; the builder tab is still a placeholder.
- [ ] GAP FILLING: Automatically generate "bridge" systems for irregular-dimension joins. Sector-level route bridge connection exists; segmentum gap filling remains future builder work.
